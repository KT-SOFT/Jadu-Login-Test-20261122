자두 음악 · 개인정보 안내

자두 음악은 YouTube 주소를 보관하고 공식 플레이어로 재생하는 웹앱입니다.

이 기기에 보관하는 자료

저장한 영상·재생목록 주소, 최근 검색어, 자두 설정, 먹이 수량, 최근 대화는 현재 브라우저의 저장 공간에 보관합니다. 로그인하지 않은 자료는 기기에 보관합니다. Google 계정으로 연결하면 저장한 곡 제목·가수·YouTube 주소와 보관함 이름을 자두 서버를 거쳐 운영자가 관리하는 GitHub 비공개 저장소에 계정별로 보관합니다. 설정·먹이 수량·대화·최근 검색어는 기기에 남습니다. 브라우저 데이터를 삭제하면 사라질 수 있으므로 목록 제목 옆 ⋯ 메뉴의 내보내기로 백업할 수 있습니다.

Google 로그인과 내 유튜브 목록

Google·Firebase의 공식 로그인 기능으로 현재 기기의 로그인 상태를 기억합니다. 아이폰·테슬라에서 내 유튜브 좋아요 가져오기를 선택한 경우에만 Google의 YouTube 계정 보기 읽기 권한을 요청합니다. 일반 보관함 로그인에서는 이 추가 읽기 권한을 요청하지 않습니다. 이 권한으로 좋아요를 표시한 동영상 목록을 Google API에서 직접 조회하며 수정·삭제·업로드는 하지 않습니다. Google 비밀번호를 자두가 받지 않습니다.

Google API의 짧은 수명 접근 토큰은 현재 브라우저 탭의 세션 공간에만 임시 보관하며, 만료를 확인하거나 자두에서 로그아웃하면 제거합니다. Google API 접근 토큰과 조회한 유튜브 목록 원문은 자두 검색 서버·GitHub·백업 파일에 보내지 않습니다. Google 로그인 유지 자료는 공식 Firebase SDK가 이 기기에 관리합니다. 조회한 개별 노래를 사용자가 저장하면 해당 주소·제목은 기기 저장 목록에 포함되며, 로그인한 경우 GitHub 개인 보관함에도 보관됩니다.

YouTube와 외부 조회

영상을 재생하면 YouTube의 공식 플레이어가 연결됩니다. 주소의 제목을 조회할 때 noembed.com에 해당 YouTube 주소를 보냅니다. 노래를 검색하면 입력한 검색어를 자두 검색 서버와 YouTube에 보내 공개 영상 제목과 주소를 가져옵니다. 더 보기에는 공개 검색의 다음 위치를 나타내는 값만 함께 보내며 Google 계정 접근 토큰은 보내지 않습니다. 공개 검색 요청에는 저장목록·최근 대화·로그인 정보를 포함하지 않으며 검색어를 데이터베이스에 저장하지 않습니다. 이 서비스에는 각 서비스의 개인정보 정책이 적용됩니다.

PC·아이폰·TV 목록 공유

목록 공유를 연결하면 PC에서 현재 표시된 추천영상·보관함과 자두에서 재생한 영상의 제목·YouTube 주소·채널명·시간을 자두 공유 서버에 보관합니다. 같은 Google 계정으로 연결한 기기만 읽을 수 있습니다. 전체 최신 10,000건을 보관하고 초과하면 오래된 자료부터 삭제합니다. 음악 파일, PC 파일 경로, 비밀번호, YouTube 쿠키와 Google API 접근 토큰은 올리지 않습니다. 로그인 확인용 Firebase ID 토큰은 HTTPS로 검증하며 서버에 저장하지 않습니다. 연결한 PC·TV는 별도의 자두 기기 연결키를 사용합니다. 목록 공유에서 기기 연결을 해제할 수 있습니다.

GitHub 개인 보관함

로그인 확인용 Firebase ID 토큰을 기존 자두 서버에서 검증한 뒤 본인 계정의 보관함 파일만 읽고 씁니다. 이 토큰은 GitHub 파일에 보관하지 않습니다. GitHub 연결키는 서버의 비밀 설정에 보관하며 공개 코드·앱·내보내기 파일에 포함하지 않습니다. 현재 목록에서 곡을 삭제해도 GitHub의 비공개 변경 이력에는 이전 목록이 남을 수 있습니다. 다른 Google 계정의 보관함은 분리하며 연결이 끊기면 기기에 저장하고 다시 연결할 때 합칩니다.

계정과 자료 이동

자두 로그아웃은 자두의 계정 연결과 현재 탭의 토큰을 지우며 원래 기기 보관함으로 돌아갑니다. 계정별 저장곡은 각 계정의 기기 공간과 GitHub 보관함에 유지됩니다. Google의 연결 관리 화면에서 자두에 준 권한을 해제할 수도 있습니다. 저장 자료 내보내기·가져오기로 본인이 파일을 관리할 수 있습니다.
